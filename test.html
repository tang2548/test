Reinforcement Learning

1. Linear Regression

หาเส้นตรง (Best Fit Line) ที่แทนความสัมพันธ์ระหว่างตัวแปร X และ Y

2. Logistic Regression

ใช้ Sigmoid Function ในการทำความสัมพันธ์ให้เป็นความน่าจะเป็น (0 ถึง 1) สำหรับจำแนกประเภท (Classification)

3. k-Nearest Neighbors (kNN)

ทำนายกลุ่มข้อมูลโดยดูจากเพื่อนบ้านที่อยู่ใกล้ที่สุดจำนวน K ตัว

4. Decision Tree

แบ่งข้อมูลด้วยโครงสร้างแบบต้นไม้ (If-Else Rules)

6. Support Vector Machine (SVM)

สร้างเส้น/ระนาบ (Hyperplane) ที่สร้างระยะห่าง (Margin) ระหว่างข้อมูล 2 กลุ่มให้กว้างที่สุด

7. K-Means Clustering

จัดกลุ่มข้อมูลที่ไม่มี Label โดยการหาจุดศูนย์กลาง (Centroid) และดึงจุดที่อยู่ใกล้เข้ากลุ่ม

8. MLP (Multi-Layer Perceptron)

โครงข่ายประสาทเทียมพื้นฐาน ประกอบด้วย Input, Hidden, และ Output Layer

10. Long Short-Term Memory (LSTM)

โครงข่ายประสาทสำหรับข้อมูลลำดับเวลา (Time-series / Sequence) ที่มี Forget Gate ช่วยจำข้อมูลระยะยาว

11. Transformer

สถาปัตยกรรมหลักของ LLM ยุคปัจจุบัน ใช้กลไก Self-Attention ในการประมวลผลข้อมูลทั้งข้อความพร้อมกัน

Self-Attention Mechanism
