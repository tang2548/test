Machine Learning Visualizer & Parameter Guide

คู่มือเจาะลึกอัลกอริทึมทั้ง 14 โมเดล พร้อมเทคนิคการปรับ Hyperparameter Tuning

1. Supervised Learning (การเรียนรู้แบบมีผู้สอน)

1. Linear Regression Regression

หลักการ: ค้นหาเส้นตรง (Best-Fit Line) ที่มีค่าความคลาดเคลื่อน (MSE) จากจุดข้อมูลจริงน้อยที่สุด เพื่อทำนายค่าตัวเลขต่อเนื่อง

⚙️ Hyperparameter Tuning:
  • fit_intercept: คำนวณจุดตัดแกน Y ($b$) หรือไม่
  • alpha ($\alpha$): (Lasso/Ridge) ควบคุมน้ำหนักบทลงโทษป้องกัน Overfitting

2. Logistic Regression Classification

หลักการ: ใช้ Sigmoid Function แปลงค่าสมการเส้นตรงให้อยู่ในช่วงความน่าจะเป็น 0 ถึง 1 เพื่อตัดแบ่งประเภทข้อมูลแบบ Binary

⚙️ Hyperparameter Tuning:
  • C: ค่าตรงข้าม Regularization (C ต่ำ = ป้องกัน Overfit สูง)
  • penalty: เลือกประเภทลงโทษ ('l1', 'l2', 'elasticnet')
  • solver: อัลกอริทึมคำนวณ เช่น 'lbfgs', 'liblinear'

3. kNN Instance-based

หลักการ: ทำนายกลุ่มข้อมูลใหม่จากการโหวตเสียงข้างมากของเพื่อนบ้านที่อยู่ใกล้ที่สุดจำนวน k จุด

⚙️ Hyperparameter Tuning:
  • n_neighbors (k): จำนวนเพื่อนบ้าน (k น้อยเสี่ยง Overfit / k มากเสี่ยง Underfit)
  • weights: การถ่วงน้ำหนัก 'uniform' หรือ 'distance'
  • metric: วัดระยะทาง เช่น 'euclidean', 'manhattan'

4. Decision Tree Tree-based

หลักการ: สร้างแตกกิ่งก้านสาขาตามคำถามเงื่อนไข โดยคัดเลือกฟีเจอร์ที่ให้ค่า Information Gain สูงที่สุดในแต่ละ Node

⚙️ Hyperparameter Tuning:
  • max_depth: ความลึกสูงสุดของต้นไม้ (คุม Overfitting)
  • min_samples_split: จำนวนข้อมูลขั้นต่ำที่ยอมให้แตกกิ่ง
  • criterion: เกณฑ์ความสะอาดข้อมูล ('gini', 'entropy')

5. Random Forest Ensemble (Bagging)

หลักการ: สุ่มสร้าง Decision Tree หลายๆ ต้น แล้วนำผลลัพธ์การทำนายของทุกต้นมาโหวตรวมกันเพื่อลดความผิดพลาด

⚙️ Hyperparameter Tuning:
  • n_estimators: จำนวนต้นไม้ในป่า
  • max_features: สัดส่วนฟีเจอร์ที่สุ่มมาใช้ ('sqrt', 'log2')
  • max_depth: ความลึกสูงสุดของแต่ละต้นไม้

6. SVM Margin-based

หลักการ: ค้นหาเส้น/ระนาบแบ่งข้อมูล (Hyperplane) ที่มีระยะห่าง (Margin) จากจุด Support Vectors มากที่สุด

⚙️ Hyperparameter Tuning:
  • C: บทลงโทษจุดที่อยู่ผิดฝั่ง (C สูง = เข้มงวดเสี่ยง Overfit)
  • kernel: ฟังก์ชันแปลงมิติ ('linear', 'rbf', 'poly')
  • gamma: รัศมีอิทธิพลของข้อมูลจุดหนึ่งๆ (ใน RBF)

8. MLP (Neural Network) Neural Net

หลักการ: โครงข่ายประสาทเทียมหลายชั้น ปรับเปลี่ยนน้ำหนัก Weights ผ่านการส่งข้อมูลย้อนกลับ (Backpropagation)

⚙️ Hyperparameter Tuning:
  • hidden_layer_sizes: จำนวน Layer และ Neuron ในแต่ละชั้น
  • activation: ฟังก์ชันกระตุ้น ('relu', 'tanh', 'logistic')
  • learning_rate_init: อัตราการปรับเปลี่ยนน้ำหนัก

13. XGBoost Boosting

หลักการ: สร้าง Decision Tree เรียงต่อกันเป็นสาย โดยต้นใหม่จะโฟกัสเรียนรู้และแก้ไขข้อผิดพลาดของต้นก่อนหน้า

⚙️ Hyperparameter Tuning:
  • learning_rate ($\eta$): อัตราการลดผลกระทบต้นใหม่ (0.01 - 0.2)
  • max_depth: ความลึกสูงสุดของต้นไม้แต่ละต้น
  • subsample: สัดส่วนการสุ่มข้อมูลเข้าฝึกฝน

14. Stacking Meta-Learning

หลักการ: รวมผลการทำนายจากหลายโมเดลหลัก แล้วส่งต่อให้ Meta-Model ทำหน้าที่สรุปผลการตัดสินใจขั้นสุดท้าย

⚙️ Hyperparameter Tuning:
  • final_estimator: โมเดลรวบรวมผลลัพธ์ (เช่น Logistic)
  • cv: จำนวน Fold ในการทำ Cross-Validation ป้องกันข้อมูลรั่ว

2. Unsupervised & Deep Learning Architecture

7. K-Means Clustering

หลักการ: จัดกลุ่มข้อมูลที่ไม่มี Label โดยคำนวณขยับจุดศูนย์กลาง (Centroid) ของกลุ่มข้อมูล K กลุ่มจนลู่เข้าที่

⚙️ Hyperparameter Tuning:
  • n_clusters (K): จำนวนกลุ่มที่ต้องการ (หาจาก Elbow Method)
  • init: วิธีการกำหนดจุดเริ่มต้นศูนย์กลาง ('k-means++')
  • max_iter: จำนวนรอบสูงสุดในการขยับจุด

9. CNN Vision

หลักการ: เลื่อนสแกนแผ่น Filter เพื่อสกัดฟีเจอร์เด่นของรูปภาพ (เช่น เส้น ขอบ มุม) ก่อนส่งต่อให้ Dense Layer

⚙️ Hyperparameter Tuning:
  • kernel_size: ขนาดของแผ่น Filter สแกนภาพ (เช่น 3x3)
  • filters: จำนวนแผ่น Filter ในชั้นประมวลผล
  • stride: ระยะการก้าวข้ามของ Filter ในการสแกน

10. LSTM Sequential

หลักการ: มีประตูควบคุมการจำ/ลืมข้อมูล (Forget/Input Gate) เพื่อประมวลผลข้อมูลอนุกรมเวลาที่มีลำดับยาวๆ

⚙️ Hyperparameter Tuning:
  • units: จำนวน Node ในชั้น LSTM Cell
  • dropout: สัดส่วนการสุ่มปิด Node ป้องกัน Overfit
  • return_sequences: การคืนค่าผลลัพธ์ทุก Time step

11. Transformer Attention

หลักการ: ประมวลผลข้อความพร้อมกันทั้งประโยคแบบขนาน โดยใช้ Self-Attention คำนวณความสัมพันธ์ระหว่างคำ

⚙️ Hyperparameter Tuning:
  • nhead: จำนวนหัวคำนวณ Multi-Head Attention
  • num_encoder_layers: จำนวนชั้นโครงสร้างประมวลผล
  • d_model: ขนาดมิติความหมายข้อมูล (Embedding Dim)

3. Reinforcement Learning (การเรียนรู้แบบเสริมกำลัง)

12. Reinforcement Learning Reward-based

หลักการ: ให้ Agent ลองผิดลองถูกใน สภาพแวดล้อม เพื่อเรียนรู้การกระทำ (Action) ที่จะได้รับ รางวัลสะสมสูงสุด

⚙️ Hyperparameter Tuning:
  • learning_rate ($\alpha$): อัตราการอัปเดตค่าความรู้ Q-value
  • discount_factor ($\gamma$): ค่าน้ำหนักรางวัลในอนาคต
  • epsilon ($\epsilon$): สัดส่วนการสุ่มลองสิ่งใหม่ (Exploration)
