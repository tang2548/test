01. Linear Regression

สร้างเส้นตรงหาความสัมพันธ์ระหว่างตัวแปรเพื่อทำนายค่านวนต่อเนื่อง (Continuous Value)

02. Logistic Regression

จำแนกกลุ่มข้อมูลแบบ 2 คลาส (Binary Classification) ด้วย Sigmoid Curve

03. k-Nearest Neighbors

จำแนกกลุ่มตามเพื่อนบ้านที่ใกล้ที่สุด k อันดับแรก

04. Decision Tree

สร้างเงื่อนไขแผนผังต้นไม้เพื่อแยกข้อมูลตามค่า Entropy / Gini Impurity

05. Random Forest

รวบรวม Decision Tree จำนวนมากร่วมกันโหวตคำตอบเพื่อลด Overfitting

06. Support Vector Machine (SVM)

หาเส้นหรือระนาบ Hyperplane ที่แบ่งกลุ่มข้อมูลให้มีระยะ Margin กว้างที่สุด

07. K-Means Clustering

การจัดกลุ่มแบบ Unsupervised Learning โดยหาจุดศูนย์กลาง Centroid

09. Convolutional Neural Network (CNN)

สกัดฟีเจอร์ของรูปภาพด้วย Filter/Kernel เพื่อการจำแนกภาพ

10. Long Short-Term Memory (LSTM)

โครงข่ายจดจำข้อมูลอนุกรมเวลา (Time-series) และลำดับประโยค

11. Transformer

สถาปัตยกรรมประมวลผลภาษา (NLP) ด้วยกลไก Self-Attention

12. Q-Learning

การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning) ผ่าน Q-Table reward

13. XGBoost

Gradient Boosting Framework ประสิทธิภาพสูงสำหรับข้อมูลแบบตาราง

14. Stacking Ensemble

นำผลทำนายจากหลายๆ โมเดลส่งให้ Meta-Model ทำนายผลสรุปขั้นสุดท้าย
