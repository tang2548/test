ML Visualizer & Dynamic Parameter Tuning

เพิ่ม/ลบ Hyperparameter ได้เองแบบ Real-time ครบทั้ง 14 โมเดล

1. Supervised Learning

1. Linear Regression Regression

หลักการ: ค้นหาเส้นตรง (Best-Fit Line) ที่มีค่าความคลาดเคลื่อนน้อยที่สุด

⚙️ Hyperparameter Tuning
  • fit_intercept: คำนวณจุดตัดแกน Y (b) หรือไม่ ×
  • alpha (α): ค่าน้ำหนักปรับลงโทษ L1/L2 ×

2. Logistic Regression Classification

หลักการ: ใช้ Sigmoid Function คำนวณความน่าจะเป็นช่วง 0 ถึง 1

⚙️ Hyperparameter Tuning
  • C: ค่าตรงข้าม Regularization (C ต่ำ = กัน Overfit) ×
  • penalty: ประเภทการลงโทษ ('l1', 'l2', 'elasticnet') ×

3. kNN Instance-based

หลักการ: ทำนายกลุ่มจากเพื่อนบ้านที่ใกล้ที่สุดจำนวน k จุด

⚙️ Hyperparameter Tuning
  • n_neighbors (k): จำนวนเพื่อนบ้าน ×
  • weights: การถ่วงน้ำหนัก 'uniform' หรือ 'distance' ×

4. Decision Tree Tree-based

หลักการ: แตกกิ่งเงื่อนไขตามค่า Information Gain

⚙️ Hyperparameter Tuning
  • max_depth: ความลึกสูงสุดของต้นไม้ ×
  • min_samples_split: จำนวนข้อมูลขั้นต่ำในการแตกกิ่ง ×

5. Random Forest Ensemble

หลักการ: สุ่มสร้าง Decision Tree หลายต้น แล้วนำผลมาโหวตรวมกัน

⚙️ Hyperparameter Tuning
  • n_estimators: จำนวนต้นไม้ในป่า ×
  • max_features: สัดส่วนฟีเจอร์ที่สุ่มมาใช้ ('sqrt', 'log2') ×

6. SVM Margin-based

หลักการ: ค้นหาระนาบแบ่งข้อมูลที่มี Margin กว้างที่สุด

⚙️ Hyperparameter Tuning
  • C: บทลงโทษจุดที่อยู่ผิดฝั่ง (C สูง = เข้มงวด) ×
  • kernel: ฟังก์ชันแปลงมิติ ('linear', 'rbf') ×

8. MLP (Neural Network) Neural Net

หลักการ: โครงข่ายประสาทเทียมหลายชั้น ปรับค่าน้ำหนักด้วย Backpropagation

⚙️ Hyperparameter Tuning
  • hidden_layer_sizes: จำนวน Layer และ Node ×
  • activation: ฟังก์ชันกระตุ้น ('relu', 'tanh') ×

13. XGBoost Boosting

หลักการ: สร้าง Decision Tree แก้ไขข้อผิดพลาดของต้นก่อนหน้า

⚙️ Hyperparameter Tuning
  • learning_rate (η): อัตราการลดผลกระทบต้นใหม่ ×
  • max_depth: ความลึกสูงสุดของต้นไม้ ×

14. Stacking Meta-Learning

หลักการ: รวมผลการทำนายหลายโมเดลส่งต่อให้ Meta-Model สรุปผล

⚙️ Hyperparameter Tuning
  • final_estimator: โมเดลสรุปผลลัพธ์ขั้นสุดท้าย ×
  • cv: จำนวน Fold ในการทำ Cross-Validation ×

2. Unsupervised & Sequential Learning

7. K-Means Clustering

หลักการ: จัดกลุ่มข้อมูลโดยขยับจุด Centroid จนลู่เข้าที่

⚙️ Hyperparameter Tuning
  • n_clusters (K): จำนวนกลุ่มที่ต้องการแบ่ง ×
  • init: วิธีวางจุดเริ่มต้น ('k-means++') ×

9. CNN Vision

หลักการ: เลื่อนสแกน Filter เพื่อดึงลักษณะเด่นของรูปภาพ

⚙️ Hyperparameter Tuning
  • kernel_size: ขนาด Filter สแกนภาพ (เช่น 3x3) ×
  • filters: จำนวนแผ่น Filter ในชั้นประมวลผล ×

10. LSTM Sequential

หลักการ: ใช้ Gate ควบคุมความจำข้อมูลอนุกรมเวลารายลำดับยาว

⚙️ Hyperparameter Tuning
  • units: จำนวน Node ในชั้น LSTM Cell ×
  • dropout: สัดส่วนการปิด Node ป้องกัน Overfit ×

11. Transformer Attention

หลักการ: ประมวลผลทั้งประโยคพร้อมกันด้วย Self-Attention

⚙️ Hyperparameter Tuning
  • nhead: จำนวนหัวคำนวณ Multi-Head Attention ×
  • d_model: ขนาดมิติความหมายข้อมูล ×

3. Reinforcement Learning

12. Reinforcement Learning Reward-based

หลักการ: ให้ Agent ลองผิดลองถูกเพื่อสะสมรางวัลสูงสุด

⚙️ Hyperparameter Tuning
  • learning_rate (α): อัตราการอัปเดตค่าความรู้ Q-value ×
  • discount_factor (γ): น้ำหนักรางวัลในอนาคต ×
