ML Visualizer & Dynamic Parameter Tuning

สามารถเพิ่ม/ลบ Hyperparameter ได้เองแบบ Real-time ในการ์ดแต่ละใบ

1. Supervised Learning

1. Linear Regression Regression

หลักการ: ค้นหาเส้นตรง (Best-Fit Line) ที่มีค่าความคลาดเคลื่อนน้อยที่สุด

⚙️ Hyperparameter Tuning
  • fit_intercept: คำนวณจุดตัดแกน Y (b) หรือไม่ ×
  • alpha (α): ค่าน้ำหนักปรับลงโทษ L1/L2 ×

2. Logistic Regression Classification

หลักการ: ใช้ Sigmoid Function คำนวณความน่าจะเป็นช่วง 0 ถึง 1

⚙️ Hyperparameter Tuning
  • C: ค่าตรงข้าม Regularization (C ต่ำ = กัน Overfit) ×
  • penalty: ประเภทการลงโทษ ('l1', 'l2', 'elasticnet') ×

3. Decision Tree Tree-based

หลักการ: แตกกิ่งเงื่อนไขตามค่า Information Gain

⚙️ Hyperparameter Tuning
  • max_depth: ความลึกสูงสุดของต้นไม้ ×
  • min_samples_split: จำนวนข้อมูลขั้นต่ำในการแตกกิ่ง ×
