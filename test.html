การแสดงผลการทำงานเชิงทัศนภาพของอัลกอริทึมยอดนิยมทั้ง 14 โมเดล

Supervised Learning

1. Linear Regression Regression

ทำนายค่าต่อเนื่องด้วยการลากเส้นตรงที่กะระยะห่างจากจุดข้อมูลทั้งหมดให้ดีที่สุด

2. Logistic Regression Classification

ใช้ Sigmoid Function แปลงค่าให้อยู่ในช่วง 0 ถึง 1 เพื่อจำแนกประเภทข้อมูล

3. kNN Instance-based

จำแนกกลุ่มจากเพื่อนบ้านที่อยู่ใกล้ที่สุดจำนวน k จุด

4. Decision Tree Tree-based

แบ่งขอบเขตการตัดสินใจเป็นแผนผังต้นไม้ตามเงื่อนไขเพื่อหาผลลัพธ์

5. Random Forest Ensemble

รวมผลโหวตจาก Decision Tree หลายๆ ต้นเพื่อเพิ่มความแม่นยำ

6. SVM Margin-based

สร้างเส้นแบ่ง (Hyperplane) ที่มีระยะห่าง (Margin) จากกลุ่มข้อมูลมากที่สุด

7. K-Means Clustering

จัดกลุ่มข้อมูลโดยค้นหาจุดศูนย์กลาง (Centroid) ของกลุ่มข้อมูล K กลุ่ม

8. MLP (Neural Network) Deep Learning

โครงข่ายประสาทเทียมแบบประมวลผลต่อกันเป็นชั้นๆ (Input-Hidden-Output)

13. XGBoost Gradient Boosting

สร้างโมเดลต้นไม้อย่างต่อเนื่อง โดยโมเดลใหม่จะปรับปรุงข้อผิดพลาดของโมเดลเก่า

14. Stacking Meta-Learning

นำคำตอบจากหลายโมเดลหลักมาส่งต่อให้ Meta-Model ทำนายขั้นสุดท้าย

Unsupervised & Sequential Learning

9. CNN Computer Vision

ใช้ Filter สแกนดึงฟีเจอร์เด่นจากรูปภาพด้วยกระบวนการ Convolution

10. LSTM Sequential

หน่วยความจำระยะยาวสำหรับประมวลผลข้อมูลอนุกรมเวลาและข้อความ

11. Transformer Attention

ประมวลผลความสัมพันธ์ของคำทั้งประโยคพร้อมกันด้วยระบบ Self-Attention

Reinforcement Learning

12. Reinforcement Learning Reward-based

Agent เรียนรู้การทำแอ็กชันผ่านการปฏิสัมพันธ์กับสภาพแวดล้อมเพื่อรางวัลสูงสุด
