01. Linear Regression

อัลกอริทึมพื้นฐานสำหรับงานพยากรณ์เชิงตัวเลข (Regression) โดยการหาเส้นตรง (Best-fit line) ที่แสดงความสัมพันธ์ระหว่างตัวแปรอิสระ (X) และตัวแปรตาม (Y) ให้มีค่าความผิดพลาดน้อยที่สุด

✔ ข้อดี

  • เข้าใจง่าย คำนวณรวดเร็ว ไม่กินทรัพยากรเครื่อง
  • แปลความหมายค่าสัมประสิทธิ์ (Coefficient) ได้ง่าย ชัดเจน
  • เหมาะเป็น Baseline Model ในการเริ่มต้นทำพยากรณ์

✖ ข้อเสีย

  • รองรับเฉพาะความสัมพันธ์แบบ "เส้นตรง" เท่านั้น
  • ไม่สามารถจับรูปแบบข้อมูลที่มีความซับซ้อน (Non-linear) ได้
  • ไวต่อค่าผิดปกติ (Outliers) อย่างมาก

02. Logistic Regression

โมเดลการจำแนกประเภท (Classification) สำหรับพยากรณ์ผลลัพธ์ที่เป็นหมวดหมู่ โดยใช้ Sigmoid Function แปลงค่าผลลัพธ์ให้อยู่ในช่วงความน่าจะเป็น 0 ถึง 1 เหมาะกับงานจำแนกแบบ 2 คลาส (Binary Classification)

✔ ข้อดี

  • คำนวณและแสดงค่าความน่าจะเป็น (Probability) ได้โดยตรง
  • ประมวลผลไว และเกิดปัญหา Overfitting ได้ยาก
  • อธิบายปัจจัยที่มีผลต่อการตัดสินใจได้ชัดเจน

✖ ข้อเสีย

  • สร้างขอบเขตการแบ่งได้เฉพาะเส้นตรง/ระนาบตรงเท่านั้น
  • ต้องเสียเวลาปรับแต่ง Feature (Feature Engineering) หากข้อมูลซับซ้อน

03. k-Nearest Neighbors (k-NN)

อัลกอริทึมการจำแนกกลุ่มแบบ Lazy Learning ที่ตัดสินใจจำแนกข้อมูลใหม่ตามกลุ่มของข้อมูลเพื่อนบ้านที่อยู่ใกล้ที่สุดจำนวน k ตัว โดยวัดจากระยะห่าง (เช่น Euclidean Distance)

✔ ข้อดี

  • หลักการเข้าใจง่ายมาก ไม่ต้องมีขั้นตอนการปรับเทรนโมเดล
  • ปรับเปลี่ยนตามข้อมูลใหม่ที่เพิ่มเข้ามาได้ทันที
  • ไม่จำเป็นต้องตั้งสมมติฐานเกี่ยวกับรูปแบบข้อมูล

✖ ข้อเสีย

  • ประมวลผลช้ามากเมื่อเจอชุดข้อมูลขนาดใหญ่
  • ใช้หน่วยความจำสูงเพราะต้องเก็บข้อมูลทั้งหมดไว้คำนวณ
  • ไวต่อสเกลข้อมูลที่ไม่เท่ากัน และข้อมูลรบกวน (Noise)

04. Decision Tree

การจำแนกข้อมูลโดยใช้โครงสร้างแผนผังต้นไม้ แตกกิ่งก้านสาขาตามเงื่อนไข IF-ELSE จากคุณลักษณะของข้อมูล โดยใช้เกณฑ์วัดอย่าง Information Gain หรือ Gini Impurity

✔ ข้อดี

  • อ่านและแปลความหมายตามเงื่อนไขการตัดสินใจได้ง่ายมาก
  • ไม่ต้องทำ Data Scaling ก่อนการนำไปใช้งาน
  • จัดการได้ทั้งข้อมูลที่เป็นตัวเลขและหมวดหมู่

✖ ข้อเสีย

  • เกิดปัญหา Overfitting ได้ง่ายมากหากต้นไม้ลึกเกินไป
  • มีความไม่เสถียร เปลี่ยนแปลงข้อมูลเล็กน้อยอาจได้ต้นไม้คนละทรง

05. Random Forest

โมเดลแบบ Ensemble Learning ที่นำ Decision Tree หลายๆ ต้นมาทำงานร่วมกัน โดยการสุ่มชุดข้อมูลและสุ่มคุณลักษณะเพื่อเทรนแต่ละต้น แล้วนำผลลัพธ์มารวมกัน (Bagging / Majority Vote)

✔ ข้อดี

  • ลดปัญหา Overfitting ได้ดีกว่า Decision Tree ต้นเดียวอย่างมาก
  • ความแม่นยำสูง และรองรับข้อมูลขนาดใหญ่ได้ดี
  • ช่วยประเมินความสำคัญของตัวแปร (Feature Importance) ได้

✖ ข้อเสีย

  • ใช้เวลาเทรนและใช้หน่วยความจำในการประมวลผลเยอะขึ้น
  • แปลความหมายและอธิบายเงื่อนไขการทำงานภายในได้ยากขึ้น

06. Support Vector Machine (SVM)

อัลกอริทึมที่หาเส้นหรือระนาบแบ่ง (Hyperplane) ที่สร้างระยะห่าง (Margin) ระหว่างข้อมูลสองกลุ่มให้กว้างที่สุด และสามารถใช้ Kernel Trick ในการจัดการข้อมูลซับซ้อนได้

✔ ข้อดี

  • ทำงานได้ดีมากในชุดข้อมูลที่มีมิติต่างๆ สูง (High-dimensional)
  • มีประสิทธิภาพสูงแม้มีจำนวนตัวอย่างน้อย
  • รองรับเส้นแบ่งซับซ้อนด้วย Kernel Trick

✖ ข้อเสีย

  • ใช้เวลาประมวลผลนานมากหากชุดข้อมูลมีขนาดใหญ่
  • ปรับจูน Hyperparameter (C, Gamma, Kernel) ให้พอดีได้ยาก

07. K-Means Clustering

อัลกอริทึม Unsupervised Learning สำหรับแบ่งกลุ่มข้อมูลโดยอัตโนมัติ โดยสร้างจุดศูนย์กลางกลุ่ม (Centroid) จำนวน K จุด และจัดข้อมูลเข้ากลุ่มที่อยู่ใกล้ที่สุดแบบวนซ้ำ

✔ ข้อดี

  • อัลกอริทึมเรียบง่าย ทำงานได้อย่างรวดเร็ว
  • ขยายการทำงาน (Scale) รองรับข้อมูลขนาดใหญ่ได้ดี

✖ ข้อเสีย

  • ต้องระบุจำนวนกลุ่ม (K) ไว้ก่อนล่วงหน้า
  • ไวต่อจุดเริ่มต้นของ Centroid และจุดรบกวน (Outliers)
  • แบ่งกลุ่มได้ดีเฉพาะข้อมูลที่เป็นรูปทรงทรงกลม/กลุ่มชัดเจน

  • การทำงานภายในเป็นแบบกล่องดำ (Black Box) อธิบายเหตุผลได้ยาก

09. Convolutional Neural Network (CNN)

สถาปัตยกรรม Deep Learning ที่ถูกออกแบบมาสำหรับประมวลผลข้อมูลที่มีลักษณะเป็นตาราง 2 มิติ โดยเฉพาะรูปภาพ ใช้ Kernel Filter ในการสกัด Feature เช่น เส้น ขอบ หรือพื้นผิว ออกมาโดยอัตโนมัติ

✔ ข้อดี

  • มีประสิทธิภาพสูงที่สุดสำหรับงานด้าน Computer Vision และรูปภาพ
  • สามารถสกัด Feature เด่นจากภาพได้เอง ไม่ต้องใช้คนสกัด
  • ลดจำนวนพารามิเตอร์ลงเมื่อเทียบกับ Fully Connected Layer ทั่วไป

✖ ข้อเสีย

  • ต้องการพลังคำนวณสูงมาก (จำเป็นต้องใช้ GPU)
  • ต้องการชุดข้อมูลรูปภาพขนาดใหญ่มากในการฝึกสอนโมเดล

10. Long Short-Term Memory (LSTM)

โครงข่ายประสาทแบบ Recurrent Neural Network (RNN) ชนิดพิเศษ ที่มีกลไก Gate (Forget, Input, Output) ในการควบคุมความจำ เหมาะสำหรับข้อมูลที่เป็นลำดับเวลา (Time-series) และภาษา

✔ ข้อดี

  • แก้ปัญหา Vanishing Gradient ใน RNN แบบดั้งเดิมได้ดี
  • จดจำความสัมพันธ์ระยะยาวของข้อมูลลำดับเวลาได้แม่นยำ

✖ ข้อเสีย

  • โครงสร้างซับซ้อน และใช้เวลาในการเทรนค่อนข้างนาน
  • ไม่สามารถประมวลผลแบบขนานได้ดีเนื่องจากต้องทำทีละลำดับ

11. Transformer

สถาปัตยกรรมหลักของงาน NLP ยุคใหม่ ที่ใช้กลไก **Self-Attention** ในการประมวลผลข้อมูลทุกตำแหน่งพร้อมกัน เป็นเบื้องหลังของโมเดลภาษาระดับโลกอย่าง GPT และ BERT

✔ ข้อดี

  • เทรนได้เร็วเพราะประมวลผลแบบขนาน (Parallel Processing) ได้ดีมาก
  • จับความสัมพันธ์ระหว่างคำที่อยู่ไกลกันได้อย่างแม่นยำสูง

✖ ข้อเสีย

  • กินทรัพยากรคำนวณและหน่วยความจำมหาศาล ($O(N^2)$)
  • ต้องใช้ข้อมูลมหาศาลสำหรับการทำ Pre-training

12. Q-Learning

อัลกอริทึม Reinforcement Learning แบบ Model-Free ที่เรียนรู้ว่า Agent ควรเลือกแอคชันใดในสถานการณ์ต่างๆ เพื่อให้ได้รับรางวัลสะสม (Reward) สูงสุดผ่านการอัปเดต Q-Table

✔ ข้อดี

  • ไม่ต้องมีความรู้หรือสร้างโมเดลเกี่ยวกับสภาพแวดล้อมล่วงหน้า
  • เรียนรู้กลยุทธ์ที่ดีที่สุดได้เองผ่านการลองผิดลองถูก

✖ ข้อเสีย

  • ไม่เหมาะกับสถานการณ์ที่มี State และ Action ขนาดใหญ่เกินไป
  • ใช้เวลาลองผิดลองถูกนานมากก่อนจะเริ่มทำงานได้อย่างถูกต้อง

13. XGBoost

อัลกอริทึมการต่อเติมต้นไม้แบบ Gradient Boosting ที่ถูกออกแบบให้มีประสิทธิภาพและความเร็วสูง มีระบบควบคุม Overfitting ในตัว และเป็นที่นิยมอย่างมากในงานแข่งขันสถิติ/วิทยาการข้อมูล

✔ ข้อดี

  • ความแม่นยำสูงมาก ทำงานได้ดีเยี่ยมกับข้อมูลรูปแบบตาราง (Tabular Data)
  • มีระบบ Regularization ช่วยป้องกันปัญหา Overfitting
  • รองรับการประมวลผลแบบขนาน ทำให้เทรนได้อย่างรวดเร็ว

✖ ข้อเสีย

  • มี Hyperparameter ให้ปรับแต่งเยอะมาก ยากต่อการจูนให้สมบูรณ์
  • เสี่ยงต่อการ Overfitting หากใช้ข้อมูลรบกวนมากเกินไป

14. Stacking

เทคนิคการผสานโมเดล (Ensemble Learning) โดยการนำผลทำนายของโมเดลที่แตกต่างกันหลายๆ โมเดล (Base Models) มาส่งต่อให้โมเดลอีกตัว (Meta-Learner) ช่วยสรุปการทำนายขั้นสุดท้าย

✔ ข้อดี

  • รวมจุดแข็งของหลายโมเดลเข้าด้วยกัน ช่วยเพิ่มความแม่นยำสูงสุด
  • ยืดหยุ่น สามารถเลือกผสมโมเดลต่างชนิดกันได้ตามต้องการ

✖ ข้อเสีย

  • ระบบมีความซับซ้อนสูง และใช้เวลาประมวลผลนานที่สุด
  • เสี่ยงต่อการ Overfitting หากกระบวนการ Cross-validation ไม่รัดกุม
